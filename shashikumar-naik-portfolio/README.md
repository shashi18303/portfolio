## 🚀 Quick Start Options

This project includes **two deployment options**:

### Option 1: Standalone Static Version (Zero Setup / Instant Preview)
If you just want to view or deploy the lightweight standalone version without installing Node.js:
1. Open `standalone/index.html` directly in any web browser (Chrome, Edge, Safari, Firefox).
2. All CSS and JavaScript are self-contained in `standalone/style.css`.

---

### Option 2: Modern React + Vite Full Application (Interactive Labs, Architecture Visualizer, Terminal)
For the modern full-stack developer portfolio with:
- Interactive Failover Simulator
- Thread-safe LRU Cache Visualizer
- Interactive Terminal with custom commands
- Live Resume PDF / Markdown Generator
- Dynamic Skills Marquee & Filtering Matrix

#### 1. Requirements:
- Node.js 18+ installed

#### 2. Install dependencies:
```bash
npm install
```

#### 3. Start development server:
```bash
npm run dev
```
Open http://localhost:3000 in your browser.

#### 4. Build for Production:
```bash
npm run build
```
The output will be in the `dist/` directory, ready to deploy to GitHub Pages, Vercel, Netlify, or any static hosting service.
